# Extras

> Things that aren't strictly required to deploy, but make the product significantly better.

---

## What's here

### `video-script/`
Loom recording script for a 10-minute first-run walkthrough. Quentin records this once, links it in the welcome message to new VIP members, and onboarding gets dramatically smoother.

### `health-dashboard/`
Single-file HTML dashboard that shows runtime status, agent activity, executions, and cost. Drop it on Vercel or open it locally. Buyers bookmark it.

---

## Setup priority

If you only build one of these for v2.0 launch: **the video script.** It removes the biggest source of failed deployments.

If you have time for both: **video + dashboard.** Buyers feel in control of their workforce.

---

## Why no auto-onboarding workflow?

VIP is sold through Skool subscription. Custom Done-For-You is invoiced manually (wire transfer or invoicing portal). Admin team handles VIP access manually for now — auto-onboarding can be added later if/when buyer volume justifies it. Manual onboarding builds real relationships in the first 50-100 buyers anyway.

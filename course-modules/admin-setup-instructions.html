Before the call — get these ready

Don't wait for the admin to ask. Have these ready when you book:

✓ Mandatory

  • Railway account — sign up at railway.app
  • GitHub username — admin needs this to add you to the private repo
  • Anthropic API key — get one at console.anthropic.com (or OpenAI)
  • Working Mac/Windows machine with Chrome or similar browser

⚡ Highly recommended

  • Slack workspace (for agent messages and approvals)
  • Stripe account (if you want payment workflows)
  • GoHighLevel + API key (if you use GHL for CRM)
  • Instagram Business account (if you want comment-to-DM)

✨ Nice to have

  • Top 3 manual tasks you want automated first
  • Example DMs / emails / posts you've sent (for brand voice tuning)
  • Your business website URL

⛔ Avoid these (they delay your setup)

  • "I'll have it ready by the call" — then the call becomes a setup-prerequisites call. Have items READY before booking.
  • No GitHub username — we can't add you to the repo without it
  • No API key budget — if Anthropic balance is $0, agents can't run
  • Vague goal — "I want AI stuff" isn't a goal. "Comment-to-DM on Instagram" is
  • Half-broken self-deploys — if you tried first, tell the admin so we can start fresh or debug knowingly

  • ✅ Come prepared with the checklist above completed
  • ✅ Be honest about your skill level — saying "I'm technical" when you're not just slows the call

Common questions

Honest answers

If your question isn't here, DM @qf_xcerebro on Instagram.

Is this actually autonomous, or another "AI does it" gimmick?

It's actually autonomous. The Tier A leadership agents run on schedule (cron) via n8n, not when you type. They delegate to Tier B specialists. Outputs go to Slack for your approval initially — once you trust a category, you graduate it to auto-fire. The Tier C library (199 markdown presets from v1.0) is the only "type-to-run" component, and that's been intentional since v1.0.

What's the difference between VIP and Custom Install?

VIP ($97/mo or $500/yr through Skool) gets you the self-install kit. You follow the guides and deploy it yourself with admin team support. Custom Install ($3K+) is done-for-you — we build, install, configure, and launch your entire system. VIP is for operators willing to get hands-on. Custom is for operators who want it done right without touching a terminal.

How do I get access after subscribing to VIP?

Subscribe through Skool, then DM @Quentin Flores or any admin tagged "Admin" in the AI Cheat Codes community. Within 24 hours, an admin will share access to the install kit, guides, and walkthrough video.

What does it cost to RUN it monthly (after install)?

~$65–$285/month total infrastructure. Breakdown: Railway hosting ~$20–80/mo (depends on traffic), Postgres ~$10/mo, LLM costs ~$30–200/mo (depends on how active your agents are — Anthropic or OpenAI). You pay these directly to those vendors. There are no recurring Xcerebro fees beyond your VIP subscription if you choose that path.

What if I bought v1.0?

DM @qf_xcerebro with your purchase email. v1.0 buyers get discounted entry into VIP. The original 199 agents are included in v2.0 as Tier C — you don't lose anything, you gain the autonomous layer on top.

I'm not technical — should I do VIP or Custom?

Custom Install is built for you. We deploy and you don't touch a terminal. VIP requires you to follow guides, copy API keys, and click through Railway. If you're comfortable with that, VIP saves money. If you're not, Custom Install pays for itself in time saved.

Does it work without Railway?

Yes. Docker Compose is included. You can deploy on Hetzner, DigitalOcean, AWS, Vultr, or any VPS. Railway is recommended because it's the fastest path (~30 minutes vs ~2 hours).

Can my data leak to Anthropic / OpenAI / anyone?

Your data goes to whichever LLM provider you configure (Anthropic by default). Anthropic's API does not train on data from API calls. All operational data (CRM, customer records, financials) stays in your own Postgres on your own Railway. No Xcerebro server in the loop. We literally don't have access to your data.

I'm a real estate operator. Is this overkill?

It's the opposite — Xcerebro was built by an active wholesaler. The REI pod (10 specialist agents) covers wholesale acquisitions, dispo, subject-to, creative finance, cold-call QA, market comps, rehab estimates, foreclosure tracking, title research, and REI marketing. If you're doing 5+ deals/year, this earns its cost in 1–2 months of saved manual work.

How does Custom Install pricing work? Is it really invoiced?

Yes. After our discovery call, we agree on scope and price (1 agent = $3K, 5 = $10K, etc.). You get an invoice via wire transfer or invoicing portal — no Stripe checkout, no recurring billing. Pay the deposit, build kicks off. Pay the balance on completion. Clean and simple.
